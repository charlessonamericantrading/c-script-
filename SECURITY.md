# Política de Seguridad

## Versiones Soportadas

Las vulnerabilidades de seguridad se corrigen en la versión activa más reciente:

| Versión | Soportada |
| --- | --- |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reportar una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en el compilador, servidor HTTP o en el almacenamiento de sesiones:

1. **NO abras un Issue público.**
2. Envía un correo electrónico a los mantenedores o abre un **Security Advisory Privado** en GitHub:
   [https://github.com/charlessonamericantrading/c-script-/security/advisories](https://github.com/charlessonamericantrading/c-script-/security/advisories)
3. Describe detalladamente el vector de ataque, un archivo `.link` de prueba o exploit conceptual.

Agradecemos tu colaboración responsable con la seguridad de la comunidad.
